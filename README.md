Calculator Web Application

A fully functional calculator web application developed using HTML, CSS, and JavaScript.

Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Percentage calculation
- Decimal number support
- Clear button
- Delete button
- Error handling
- Divide-by-zero protection
- Keyboard input support
- Responsive design
- DOM manipulation
- Event handling

Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling

Keyboard Controls

Key| Function
"0-9"| Enter numbers
"+"| Addition
"-"| Subtraction
"*"| Multiplication
"/"| Division
"%"| Percentage
"Enter"| Calculate
"Backspace"| Delete
"Escape"| Clear

How to Run

1. Download or clone this repository.
2. Open "index.html" in Google Chrome, Microsoft Edge, or another web browser.
3. Start using the calculator.

Project Objective

This project was created to practice DOM manipulation, event handling, input parsing, arithmetic operations, keyboard events, and error handling using JavaScript.
